## 6. Buddy System 算法实现

```text
请基于当前 uCore Lab2 框架实现可通过 make PMM=buddy 选择的 Buddy System 物理页分配器，并严格遵守 struct pmm_manager 公共接口。

要求：
1. 设置 BUDDY_MAX_ORDER=15，维护 0～15 阶空闲链表；第 k 阶块包含 2^k 个连续页，起始 PFN 按 2^k 对齐。
2. init_memmap(base, n) 必须支持多次调用，以及起点不对齐、长度不是二次幂的合法区域。
3. 初始化时从低地址开始，把区域贪心拆分成“不超过剩余长度且满足当前 PFN 对齐”的最大二次幂块。
4. 非二次幂请求向上取整到最小 2^k 页，例如 3 页按 4 页、5 页按 8 页处理。
5. 分配时从目标阶向上寻找第一个非空链表，并把较大块逐级二分；另一半加入低一阶链表。
6. 释放时通过 buddy_pfn = pfn ^ (1 << order) 计算唯一伙伴。只有伙伴在合法范围内、为空闲块且阶数相同时才允许合并。
7. 相邻且大小相同不一定是伙伴，禁止仅凭地址相邻执行合并。
8. 仅空闲块首页设置 PG_property；property 保存阶数。已分配块首页保留必要的阶数信息，以便释放时校验。
9. buddy_nr_free 按实际 2^k 页数增减，而不是按原请求 n 增减。
10. 超过最大阶或找不到可用块时返回 NULL，并保证失败状态不变。
11. 增加审计函数，检查链表链接、地址范围、块对齐、元数据、块重叠、可合并伙伴和总页数一致性。
12. 在 Makefile 和 pmm.c 中接入管理器，不修改其他模块的公共接口。

完成后解释阶数计算、初始化拆分、分配拆分、唯一伙伴和级联合并，并使用 -Wall -Werror 编译验证。
```
